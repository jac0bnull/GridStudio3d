# Changelog
## 0.1.0-alpha — local candidate
First standalone Windows workbench; real Poly Haven catalogue and checksummed downloads; local library, 3D viewport and scene persistence; visual HUD design; self-contained Unity export. See docs/ACCEPTANCE.md for limitations and actual checks.
## 0.1.1-alpha — Marketplace discovery
Popular home ranking, debounced Icosa Gallery search, explicit Google search shortcut, source file links and attribution, complete gallery installations, and a global export menu.
## 0.2.1-alpha — Multilingual discovery
- Search across categories with the original text and an English lookup term. Preserve free-first ordering and distinguish provider outages from empty results.
- Show matching Synty storefront offers with current prices and currency after free catalogs are exhausted.
- Animate each seasonal landscape and respect the system reduced-motion preference.

## 0.2.0-alpha — Personal workbench
Four selectable seasonal workbench themes, a single export menu, installed assets sortable by download time, per-user download locations with legacy library lookup, and a self-contained Windows x64 distribution.
