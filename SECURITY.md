# Security
This alpha targets trusted local projects. Do not import unknown Unity editor scripts into an important project; exported C# runs with Unity's permissions. Use a disposable project for inspection. Keep operating systems, browsers, Unity and dependencies patched. For a vulnerability, send maintainers a private reproducer via GitHub private vulnerability reporting once the repository is published. Until a private contact is configured, withhold exploit details and request a private channel. Never attach credentials, save keys, logs with personal paths, or unlicensed assets. No telemetry endpoint or account service is provided.
